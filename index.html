      Setup

      Each part takes a few minutes, and you only need the parts you want.

      🔑 Connect AI keys (in the app)
      1. Open the app, then click Settings.
      2. Paste any keys you have, then click Test & load models for each:
        • Claude: Anthropic console
        • GPT: OpenAI platform
        • Gemini: Google AI Studio
        • AWS Bedrock: Bedrock API keys, plus pick your region
        • Any API: choose OpenRouter, Groq, Mistral, DeepSeek, xAI, Together or a custom URL
      3. Click Save, untick Demo, and press ⚡ Kickstart.
      ☁️ Turn on cloud agents (GitHub)
      1. Open the repo's Actions secrets page.
      2. Add any of these secrets. Each one switches on its agent:
        ANTHROPIC_API_KEYClaude Code (ultracode) + the merge step
        AWS_BEARER_TOKEN_BEDROCKClaude Code through AWS Bedrock
        OPENAI_API_KEYOpenAI Codex
        GEMINI_API_KEYGoogle Gemini CLI
      3. In the app, write a task and click Send task to cloud agents.
      💬 Connect KakaoTalk
      1. Create an app at developers.kakao.com.
      2. Under Platform → Web, add the site domain https://speddiikga-code.github.io.
      3. Under Kakao Login, turn it on and add the Redirect URI https://speddiikga-code.github.io/relay/app/.
      4. Under Consent items, enable "Send message in KakaoTalk" (talk_message).
      5. In the app, go to Settings → KakaoTalk, paste the REST API key, press Connect KakaoTalk, then Send test message.

      Questions

      Is this really Claude Code's ultracode?

      In the browser, Relay runs its own orchestration (the pipelines above) directly against the model APIs. In the cloud agents, it runs the real Claude Code CLI with the documented ultracode setting turned on. The typed ultracode: keyword works only when a person types it into Claude Code, by design, so no website can trigger it.

      What does it cost?

      Relay itself is free. You pay each AI provider for the tokens your runs use, on your own keys. The app shows tokens and an estimated cost per agent and per run. Try the calculator above.

      Can it read my files or my repository?

      The browser app can't. Paste in what the agents need. The cloud agents can read the repository they run in (read-only), and they answer in comments rather than pushing code.

      Can other people use my keys?

      No. Your keys are stored only in your own browser, so visitors to the site use their own. Cloud runs start only for the repository owner.
