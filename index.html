How it works

Three steps, and the second one is optional.

  1. 1

    Connect your AIs

    Paste the API keys you have into Settings: Claude, GPT, Gemini, AWS Bedrock, or one OpenRouter key for hundreds of models. Connect any subset. If a pipeline wants a service you don't have, a connected one stands in.

  2. 2

    Describe the task

    Write what you want, and paste any code or text the agents need. Start with ultracode: to throw everything at it, or say "ask all the models" to get the Council.

  3. 3

    Press ⚡ Kickstart

    Relay picks the cheapest orchestration that fits and runs it. You watch every agent stream live, with tokens and estimated cost, and the result can go straight to your KakaoTalk.

Seven ways to orchestrate

Every pipeline is editable: add stages, pick models per stage, and change the prompts. You can also export and import pipelines as JSON.

Solo

1 call
Claude

One agent. The lowest rung, and enough for most tasks.

Compare

2 calls
Claude‖GPT

Two independent answers side by side, for a second opinion.

Relay

3 calls
Draft→Attack→Revise

A different lab attacks the draft before you see it. Good for high-stakes work.

Debate

5 calls
Answer‖Answer→Cross-examine→Judge

For audits and anything that has to be verified, not just confidently stated.

Fan-out

N + 3 calls
Plan→N workers→Refute→Merge

Many similar items handled the same way, like docs for every service or a review of every file.

Council

every AI + 1
Every connected AI→Judge

Breadth and consensus: where models agree, it's likely right. Where they disagree, the judge decides.

Ultra

N + 7 calls
Plan→Workers→2 refuters→Merge→Attack→Fix

Both vendors at every step, at xhigh effort. For when it has to be right. Triggered by ultracode:.

Cloud agents

Real coding agents, working in parallel

One click sends your task to GitHub Actions, where these agents work on it at the same time. Then Claude merges their answers. Each result arrives as a comment on a GitHub issue.

  • Claude Code with ultracode on: xhigh effort plus multi-agent workflows, through the Anthropic API or AWS Bedrock
  • OpenAI Codex at xhigh reasoning effort
  • Google Gemini CLI

Only the repository owner can start a run, and each agent runs only if its key is saved as a repository secret. The ultracode: keyword works only when a person types it into Claude Code, so the cloud agents turn ultracode on through its documented setting.

TALK

Results in your KakaoTalk

Connect KakaoTalk once and Relay messages you ("나와의 채팅") whenever a run finishes. Every final answer also gets a one-tap KakaoTalk button.

Private by design

  • No server. Relay is a static page. Your keys stay in your browser and go straight to each AI vendor.
  • Keys stay local. By default they last only for the tab; saving them on the device is opt-in.
  • Locked down. A strict Content-Security-Policy blocks other scripts, and every AI answer is sanitized before it's shown.
  • Spend guards. You can cap agent calls per run, cap fan-out size and concurrency, and stop any run instantly.

Setup

Each part takes a few minutes, and you only need the parts you want.

Connect AI keys (in the app)
  1. Open the app, then click Settings.
  2. Paste any keys you have, then click Test & load models for each:
    • Claude: Anthropic console
    • GPT: OpenAI platform
    • Gemini: Google AI Studio
    • AWS Bedrock: Bedrock API keys, plus pick your region
    • Any API: choose OpenRouter, Groq, Mistral, DeepSeek, xAI, Together or a custom URL
  3. Click Save, untick Demo, and press ⚡ Kickstart.
Turn on cloud agents (GitHub)
  1. Open the repo's Actions secrets page.
  2. Add any of these secrets. Each one switches on its agent:
    ANTHROPIC_API_KEYClaude Code (ultracode) + the merge step
    AWS_BEARER_TOKEN_BEDROCKClaude Code through AWS Bedrock
    OPENAI_API_KEYOpenAI Codex
    GEMINI_API_KEYGoogle Gemini CLI
  3. In the app, write a task and click Send task to cloud agents.
Connect KakaoTalk
  1. Create an app at developers.kakao.com.
  2. Under Platform → Web, add the site domain https://speddiikga-code.github.io.
  3. Under Kakao Login, turn it on and add the Redirect URI https://speddiikga-code.github.io/relay/app/.
  4. Under Consent items, enable "Send message in KakaoTalk" (talk_message).
  5. In the app, go to Settings → KakaoTalk, paste the REST API key, press Connect KakaoTalk, then Send test message.

Questions

Is this really Claude Code's ultracode?

Two different things are involved. In the browser, Relay runs its own orchestration (the pipelines above) directly against the model APIs. In the cloud agents, it runs the real Claude Code CLI with the documented ultracode setting turned on. The typed ultracode: keyword works only when a person types it into Claude Code, by design, so no website can trigger it.

What does it cost?

Relay itself is free. You pay each AI provider for the tokens your runs use, on your own keys. The app shows tokens and an estimated cost per agent and per run. Start with Solo, and move up the ladder only when a task needs it.

Can it read my files or my repository?

The browser app can't. Paste in what the agents need. The cloud agents can read the repository they run in (read-only), and they answer in comments rather than pushing code.

Can other people use my keys?

No. Your keys are stored only in your own browser, so visitors to the site use their own. Cloud runs start only for the repository owner.
