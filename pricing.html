Relay is open source and runs in your browser. The paid plans exist for one honest reason: cloud agent runs cost us real API credit.

Read this before you pay anything. Relay is bring your own key. In the browser app you paste your own Anthropic, OpenAI, Gemini or Bedrock key, and you pay those vendors directly at their rates. Relay never takes a cut of that and never sees those keys.

Questions people actually ask

If it's open source, why would I pay?

For the browser app, you shouldn't. It's free, it's yours, fork it. You pay only when we spend money on your behalf — cloud agent runs burn real API credit on our account — or when your company needs invoicing and a support commitment that a GitHub issue tracker can't give.

Why is Cloud a waitlist instead of a buy button?

Because it isn't built yet, and we'd rather say so. Cloud runs need a server to hold the API keys and meter usage. Relay today is a static site with no backend — that's why your keys never leave your browser. Adding cloud runs means adding that server, and we won't take money for it before it exists.

Can I just fork it and remove the paywall?

Yes, and that's fine. Everything in the browser app is free and MIT-ish by design — there is no paywall in it to remove. The only thing you can't fork is our API credit, which is the one thing the paid plans actually sell.

Do you see my API keys?

No. Browser keys live in your sessionStorage (or localStorage if you tick Remember) and are sent only to that provider's own API. There is no server to send them to. Set spend limits in each vendor's console, and don't tick Remember on a shared computer.

Refunds?

Cancel any time and the plan runs to the end of the period. For Korean consumers, the statutory withdrawal rights under 전자상거래법 apply and are not waived by anything on this page.
